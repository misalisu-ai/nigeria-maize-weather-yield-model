# 3MTT Submission Checklist

- [ ] Streamlit app runs from a fresh environment
- [ ] requirements.txt contains streamlit and plotly
- [ ] All five dashboard pages load without errors
- [ ] Climate Stress controls return one valid scenario row
- [ ] Model Performance tables load from committed result CSVs
- [ ] Explainability page switches between temporal and spatial SHAP
- [ ] README includes local run command
- [ ] GitHub repository is public or accessible to evaluators
- [ ] Demo video is 2–3 minutes and shows the working app
- [ ] Pitch deck exported and reviewed
- [ ] No climate-stress result is described as a future forecast
- [ ] Final commit/tag created for submission version
